# Salary Calculator

A Hebrew shift salary calculator built with Vite and TypeScript.

## Features

- חשבון שכר לפי שעה
- הזנת שעות ידנית או לפי שעת התחלה וסיום
- חישוב שעות נוספות עבור יום רגיל, שבת/מנוחה, חג ויום בחירות
- תצוגה מודרנית ועיצוב רספונסיבי

## Deploy

This project is configured for GitHub Pages deployment.

- Build: `npm run build`
- GitHub Pages branch: `gh-pages`

The site is intended to publish at:

`https://kidker95.github.io/salary-calculator/`
